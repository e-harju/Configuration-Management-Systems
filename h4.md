## a. & b.

Asensin PostgreSQL -demonin tunnilla. Ei ole käytetty aikaisemmissa tehtävissä. Tässä ohje: https://terokarvinen.com/2016/install-postgresql-on-ubuntu-new-user-and-database-in-3-commands/.

- sudo apt-get update

- sudo apt-get -y install postgresql

- sudo systemctl start postgresql

- sudo -u postgres createuser elias

- sudo -u postgres createdb elias --owner elias

- psql
