## a. & b.

Asensin PostgreSQL -demonin tunnilla. Ei ole käytetty aikaisemmissa tehtävissä.

```linux
sudo apt-get update

sudo apt-get -y install postgresql

sudo systemctl start postgresql

sudo -u postgres createuser elias

sudo -u postgres createdb elias --owner elias

psql
```

Tein myös automatisoinnin tunnilla. Alla oleva koodi kirjoitettu pääosin ulkomuistista paitsi tarkistin netistä nuo community.postgresql parametrit.

```yaml
- name: Install PostgreSQL
  hosts: all
  become: yes
  apt:
    name:
      - postgresql
    state: present

- name: Start PostgreSQL
  service:
    name: postgresql
    state: started
    enabled: yes

- name: Create database user
  become_user: elias
  community.postgresql.postgresql_user:
    name: elias
    state: present

- name: Create database
  become_user: elias
  community.postgresql.postgresql_db:
    name: elias
    owner: elias
    state: present
    
```
