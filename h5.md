## x.

- Pro Git on Scott Chaconin ja Ben Straubin kirjoittama ohje Gitin käyttöön

<br>

- Git on versionhallinta ohjelma
- Lähes kaikki operaatiot tehdään lokaalisti
- Itse pidän kirjasta, koska siinä on kaikki tarvittavat ohjeet yhdessä paikassa

<br>

- Käytän komentojen selityksessä Git dokumentaatiota
- git add --all, ennen tietojen tallennusta ne pitää siirtää ns. "valmiustilaan"
- git commit, tekee tallennukset gitiin
- git pull, vetää päivitetyt tiedot git repositoriosta lokaalille laitteelle
- git push, työntää commitit lokaalilta laitteelta git repositorioon
